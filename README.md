# i7mi7 · a little place to call home

数字媒体艺术个人作品集。复古星空、可拖拽欢迎牌、低多边形仓鼠与物品、喂食与抚摸互动、便签式作品展示。

## 网站文件

`outputs/index.html` 是完整的单文件网站，内嵌字体、图片、模型和脚本，无需安装依赖或访问第三方资源。直接双击打开，或通过静态服务器预览即可。

## 部署

仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
推送 `main` 后，Pages 工作流发布 `outputs` 目录。也可在 Actions 中手动运行。

Git 仓库只包含发布所需的单文件网页、说明和部署工作流。本地参考图、生成服务配置、依赖缓存及工作文件不上传。

## 手机支持

支持窄屏、横屏、安全区和便签内部滚动。图片可用三角按钮切换，欢迎牌可触摸拖拽，仓鼠可来回抚摸；系统开启减少动态效果时会减少动画。

实际设备仍需支持 WebGL；设备性能和浏览器设置可能影响 3D 动画帧率。
